# AISuite Project demo of @aisuite-eu/ngtools
25/09/2026 : first version, Angular 22
    - version number start at 3.0.1 since it is refactoring work using Claude Code from AI Suite World Desk Reference (WDR)
    - one page application with tab panels (no router), one tab per family of components of the library, tabs loaded on first opening
    - mocked AI Suite server (interceptor and data in src/app/mock), so the demo runs on its own
    - LinSce labels: language switch with ais-flag-button, labels in en, fr, de, it, es
    - flags in public/assets/flags, Bootstrap 5 and Font Awesome for the look of the components
    - ng lint (angular-eslint) with accessibility rules on templates
